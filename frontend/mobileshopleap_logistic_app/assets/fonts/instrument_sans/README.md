Instrument Sans is bundled with the app for offline use.

Source: https://github.com/Instrument/instrument-sans/tree/master/fonts/ttf
License: SIL Open Font License 1.1; see OFL.txt.

The fonts include regular, medium, semibold, and bold weights (400–700), with
normal and italic styles. Existing Flutter font weights remain
unchanged; heavier requests use the family's available bold face.
